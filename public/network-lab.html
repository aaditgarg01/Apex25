How to compare fairly

Join with two devices, wait for both drivers, then start. The test uses eight cars total and three dry laps. Use the repeatable drive for at least 60 seconds in each option, keeping graphics, browser and connection the same.

Photon currently runs race simulation in the creator’s browser worker. Host results have a local shortcut and must not be compared with a remote server. Use guest results; even those compare different hosting arrangements. This is a development prototype with no host migration.

Input delay measures acknowledgement by the simulation. Connection ping measures a nearer networking endpoint and is not interchangeable with input delay. Data is decoded application payload, not actual compressed wire usage. Normal braking, steering and collisions also affect the movement measurements in the downloaded report.

Photon’s free development app has a 20-user total limit. The live game continues to use the current APEX server.
